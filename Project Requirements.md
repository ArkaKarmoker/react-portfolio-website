# React Assignment: Personal Portfolio Website

## Project Overview

Project Name: Personal Portfolio Website

### Objective

Build a responsive and interactive Personal Portfolio Website using React.js. The purpose of this project is to practice React fundamentals and intermediate concepts by creating a real-world application.

Your portfolio should introduce yourself, showcase your skills, display your projects, and allow visitors to contact you.

## 1. Required Sections

Your portfolio website must contain the following sections:

### A. Navbar

* Display your name or logo.
* Add navigation links:
  * Home
  * About
  * Skills
  * Projects
  * Contact
* Navbar should be responsive.
* Clicking a navigation link should navigate to the relevant section.

### B. Home / Hero Section

* Display your name.
* Add a professional title (e.g., Frontend Developer).
* Write a short introduction about yourself.
* Add a profile picture.
* Add two buttons:
  * Download CV
  * View Projects

### C. About Me

* Write a short description about yourself.
* Include your educational background.
* Mention your career goals.
* Display your profile information.

### D. Skills Section

Display your technical skills using cards, badges, or progress bars.

Example:

* HTML
* CSS
* JavaScript
* React.js
* Tailwind CSS
* Git & GitHub

### E. Projects Section

Display at least 4 projects.

Each project card should contain:

* Project image or screenshot.
* Project title.
* Short description.
* Technologies used.
* Live Demo button.
* GitHub button.

Important: Store project information in an array and display the cards using the `.map()` method.

### F. Contact Section

Create a contact form with:

* Name
* Email
* Subject
* Message
* Submit button

Requirements:

* Use React state to manage form inputs.
* Handle form submission using `onSubmit`.
* Validate that required fields are filled.
* Display a success message after successful validation.

### G. Footer

* Display your name.
* Add social media links (GitHub, LinkedIn, Facebook).
* Add a copyright message.

## 2. Additional Features

Complete at least 3 of the following 5 features:

1. Dark/Light Mode: Add a theme toggle button.
2. Project Filtering: Filter projects by technology (React, JavaScript, CSS, etc.).
3. Mobile Responsive: Make the website responsive for mobile, tablet, and desktop.
4. Scroll to Top: Add a button that takes visitors to the top of the page.
5. Dynamic Navbar: Highlight the active navigation section while scrolling.

## 3. Project Rules

* Use React functional components.
* Use proper component naming conventions.
* Do not write the entire application in a single file.
* Use clean and readable code.
* Use meaningful variable and function names.
* Do not copy an existing portfolio template completely.
* Use your own content and design.
* Ensure there are no console errors.

## 4. Submission Requirements

Students must submit:

1. Complete source code (GitHub repository).
2. Live website link (Vercel or Netlify).
