  5. **Ecommerce API:** High-concurrency DRF e-commerce backend with Redis DFS category tree caching, Strategy Pattern payment routing (Stripe, bKash), and PostgreSQL row-level locking.

## 🚀 Getting Started

### 1. Clone Repository

```bash
git clone https://github.com/ArkaKarmoker/react-portfolio-website.git
```

### 2. Navigate to Project Directory

```bash
cd react-portfolio-website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run Development Server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Run Automated Tests

```bash
npm test
```

### 6. Run Code Linter

```bash
npm run lint
```

### 7. Build for Production

```bash
npm run build
```

Production output will be generated inside the `dist/` directory.

### 8. Preview Production Build

```bash
npm run preview
```
